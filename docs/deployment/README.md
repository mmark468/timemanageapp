# 部署说明

## 生成部署文件

```bash
npm install
npm test
npm run build
```

把生成的 `dist/` 整体部署到静态网站服务即可。资源路径使用相对路径，支持根域名和子目录部署。

## 部署检查

- 使用 HTTPS，文件分享和持久存储能力会更稳定。
- 不要只上传 `index.html`，必须同时上传 `dist/assets/`。
- 部署域名或协议变化会形成新的浏览器存储空间，原域名的本地资料不会自动迁移。
- 清除站点数据、无痕模式结束或卸载封装 App 会删除本地资料。
- Web 前端不需要 Python 后端即可运行；题库索引服务需要单独部署。

## 当前发布边界

仓库还没有 CI/CD 工作流，也没有自动发布配置。当前适合手动构建后部署 `dist/`；正式发布前建议先补自动构建与浏览器端回归测试。
