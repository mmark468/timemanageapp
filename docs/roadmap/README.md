# 后续改进建议

## 优先级 1：发布可靠性

- 增加 GitHub Actions：类型检查、测试、构建和静态部署。
- 增加真实浏览器 E2E：导入、重复文件、重启恢复和删除级联。
- 显示浏览器可用空间，并在接近配额时提前提醒。

## 优先级 2：资料能力

- 使用内容哈希提高重复文件识别准确度。
- 增加资料库备份与恢复，避免换设备或换域名后无法迁移。
- 为 PDF 和图片接入 OCR、卷子识别与全文搜索。
- 评估 OPFS、PWA 或桌面 / 移动原生封装，获得更稳定的大文件体验。

## 优先级 3：可选同步

- 在保持“默认不上传”的前提下，提供用户主动开启的加密云同步。
- 为同步增加冲突处理、版本记录和离线队列。
