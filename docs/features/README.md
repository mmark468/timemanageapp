# 当前功能

## 学习规划

- 首次档案与课表设置。
- 今日任务、学习时间轴和番茄钟。
- 月历、考试、假期、DDL 与日程编辑。
- 学校周课表和 A/B 周支持。
- A-Level 数学试卷查找、状态和题目整理。

## 本地资料库

- 新建、编辑、删除和排序科目，可设置图标与颜色。
- 每个科目只包含“卷子”和“学习资料”。
- 系统文件选择器批量导入 PDF、Word、PowerPoint、图片和 TXT。
- 文件与元数据保存在设备浏览器 IndexedDB，不自动上传。
- 全局搜索、收藏、最近打开和三种排序方式。
- 重命名、移动、删除、分享、导出和外部打开。
- PDF、图片和 TXT 可在 App 内预览；其他格式提供系统打开或导出。
- 对重复、超大、不支持、缺失或无法读取的文件显示明确提示。

## 适配范围

- 竖屏手机：单列内容与底部导航。
- 平板和电脑：左侧导航与多栏工作区。
- 浅色和深色主题沿用现有设计系统。
