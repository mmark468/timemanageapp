## 设计思路

本阶段继续保留原来的浅色、圆角、柔和阴影和毛玻璃视觉，不重写设计系统。响应式策略是移动端优先：手机竖屏仍然是单列页面和底部导航，宽屏端再切换为更完整的工作台结构。

桌面端的核心目标不是增加装饰，而是提升信息密度和可操作性。左侧侧边栏承接全局导航，主要页面内部再使用两栏或三栏布局，让任务、日历、资料库和搜题可以在一个屏幕里完成更多操作。

日历的设计参考桌面日历软件的管理方式：左侧负责月份与日期选择，右侧负责当天时间线和新增 / 编辑动作。中国假期、考试、特别事项和 DDL 使用小标签而不是大面积颜色块，保证一眼可扫读，也避免月历显得混乱。

搜题模块的桌面端定位改为“试卷管理 + 拍照搜题入口”。左侧选择试卷，右侧顶部保留拍照上传，旁边加入状态、题目整理和试卷分类归纳，减少右侧空白。

资料库从学习进度模块转向本地文件整理：后续可以接入用户本地文件索引，围绕真题、答案、笔记、未归档文件和快速搜索搭建功能，而不是把科目页做成单纯进度条。

## 断点与布局

- 默认：竖屏手机单列布局，底部导航固定，卡片和表单保持手机可触控尺寸。
- `md` / 768px：启用桌面侧边栏导航，主页面开始使用两栏布局。
- `lg` / 1024px：日历、首页、搜题、资料库等重点页面进入更完整的宽屏工作区。
- `xl` / 1280px：放大核心内容列宽，最大页面宽度维持在 1440px 内。
