## 本阶段目标

在不依赖服务器、不破坏现有学习规划功能的前提下，把现有资料入口升级为可真实使用的本地资料库。资料结构固定为“科目 → 卷子 / 学习资料”，文件内容与元数据保存在浏览器本地，科目与文件操作按服务层、存储层和页面组件分离。

## 预计改动范围

- 新增资料库领域类型、本地数据库、文件存储和导入服务。
- 新增资料库首页、科目详情、文件预览和复用型对话框组件。
- 调整应用路由及资料入口，保留原有科目学习功能的数据边界。
- 添加基础自动化测试、异常提示、空状态和响应式布局。

## 本地保存位置

- 浏览器数据库：IndexedDB `finished-local-library`。
- 文件内容：`files` store 中的 Blob。
- 文件元数据：`resources` store。
- 科目元数据：`subjects` store。
- 数据不会经过项目 Python 后端，也没有云端上传调用。
