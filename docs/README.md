# 项目文档导航

这里把不同用途的说明分开，先看与你当前任务有关的文件即可。

| 文件夹 | 适合谁 | 内容 |
| --- | --- | --- |
| `getting-started/` | 第一次运行项目的人 | 安装、启动、测试 |
| `features/` | 产品与测试人员 | 当前已完成功能 |
| `architecture/` | 想了解项目结构的人 | 目录和模块关系 |
| `deployment/` | 负责发布的人 | 构建、部署和数据注意事项 |
| `roadmap/` | 产品与开发人员 | 后续改进顺序 |
| `internal/` | Codex 与专业开发人员 | 技术约束、数据库和部署审计 |
| `archives/` | 需要追溯阶段变化的人 | 按日期保存的阶段记录 |

建议普通使用者先读 [运行说明](getting-started/README.md) 和 [功能清单](features/README.md)。
