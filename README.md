# 时间规划

时间规划是面向中国国际学生，尤其是 A-Level / IGCSE / IB / AP 备考学生的移动端优先学习时间管理 App。它不是普通日历，而是把学校课表、学习日历、考试倒计时、科目与单元进度、专注记录和 A-Level 搜题合在一起的学生日常规划工具。

当前仓库包含 Web MVP、小程序端适配稿、CAIE 试卷索引后端和本地内容索引工具。学习规划数据使用 localStorage，本地资料库使用 IndexedDB 保存元数据和文件 Blob。

## 产品定位

- 服务对象：中国国际学校学生、A-Level 学生、IB / AP / IGCSE 学生，以及 SAT / IELTS / TOEFL 备考学生。
- 核心任务：帮助学生把课程、作业 DDL、模拟考试、大考、复习单元和专注时间放进同一个规划系统。
- 使用场景：每天查看今日安排，按周维护课表，按月查看学习日历，按科目推进单元进度，遇到 A-Level 数学题时快速搜索相似题。
- MVP 边界：当前不包含登录、云同步、支付、通知推送、AI 自动排课或真实线上账号体系。

## 网站需求

- 移动端优先，目标视口接近 iPhone 390px 宽度。
- 横屏手机、平板横屏和电脑端需要切换为更像 Web App 的宽屏布局，而不是把手机页面拉宽。
- 首页必须直接进入可用的学习规划体验，不做营销落地页。
- 竖屏手机保留底部 5 个 Tab：今天、日历、科目、课表、搜题。
- 768px 以上启用桌面侧边栏导航，主内容区独立滚动；最大内容宽度控制在 1440px 内。
- 日历和课表是核心能力，必须支持真实编辑、查看和数据保存，而不是静态视觉 demo。
- 用户首次进入需要完成个人档案、课程体系、考试局、科目和课表设置。
- 学习任务需要能同步进入日历、今日时间轴、学校课表或番茄钟目标。
- A-Level 搜题需要支持关键词、拍照上传、科目、年份、月份、卷号、Paper 类型、试卷状态和错题记录。

## 设计思路

- 视觉方向：黑白 / 浅灰为主，白色圆角卡片承载信息，红色只用于大考、紧急事件等高优先级状态。
- 信息密度：面向学生每天重复使用，保持紧凑、可扫读，避免装饰性大卡片和过多说明文案。
- 交互原则：常用动作尽量一屏可达；任务、课表、日历、科目进度之间要能互相跳转。
- 响应式原则：手机端保留单列和底部导航；宽屏端改为左侧导航 + 右侧功能区，避免内容空洞。
- 日历原则：课程 / 休息是有开始和结束时间的日程，任务是带 DDL 的事项；两类内容在同一个日历里汇总。
- 月历原则：用少量语义标签标出中国假期、考试、特别事项和 DDL，避免使用过多颜色造成认知负担。
- 产品语气：像真实学习工具，不像展示型 demo；减少说教，让学生专注于下一步要做什么。
- 组件风格：移动端底部导航、圆形图标按钮、紧凑列表、清晰状态标签和可编辑表单。

## 技术栈

- React + Vite
- TypeScript
- Tailwind CSS
- lucide-react 图标
- localStorage 保存个人档案、任务、课表、今日时间轴、放假时间、单元进度、搜题记录和番茄钟记录
- IndexedDB 保存本地资料库科目、文件元数据和文件 Blob
- Python + SQLite 用于 CAIE past-paper 元数据、PDF 索引和 OCR 搜索后端实验

## 已完成功能

- 响应式 AppLayout：手机端底部导航 + 单列内容，768px 以上切换为桌面侧边栏 + 独立滚动主内容。
- 欢迎页与 onboarding：姓名、年级、课程体系、考试局和科目选择。
- 首次课表设置：每门课的每周次数、星期、开始时间、结束时间和教室。
- 今日首页：桌面端左侧聚合今日任务、搜题入口和今日日历，右侧承载番茄钟和专注统计。
- 学习日历：桌面端左侧选择月份 / 日期，右侧管理当天时间线；大考、临时考试、中国假期、特别事项和 DDL 都有清晰标注。
- 学习任务：添加、完成、编辑、删除，并可同步到日历、时间轴、课表或番茄钟目标。
- 课表：学校周 / 自定义计划、A/B 周、课程总量列表、批量编辑和单节微调。
- 本地资料库：按科目管理“卷子 / 学习资料”，支持批量导入、搜索、排序、收藏、移动、重命名、删除、分享、导出和预览。
- 番茄钟：自定义专注时长、休息规则、当前目标和完成历史。
- A-Level 搜题：按科目、年份、月份和卷号选择 9709 试卷；卷号旁标明 Pure Math / Mechanics / Statistics。
- 试卷状态管理：默认为没做过，可标记做过一遍、正在学习、完整理解，左侧用克制书签色条提示状态。
- 题目整理：可在试卷归纳中输入错题题号，选择是否记录分数，并保存到本地试卷记录。
- 小程序端适配稿：保留 Web MVP 的核心页面与本地 storage 数据思路。
- CAIE 试卷索引实验：公开 Cambridge past-paper 元数据、PDF 文本索引、SQLite FTS 搜索和 OCR 搜索接口。

```text
content/cie-math/                 # CAIE Mathematics 9709 内容索引目录
wechat-miniprogram/               # 原生微信小程序适配稿
```
